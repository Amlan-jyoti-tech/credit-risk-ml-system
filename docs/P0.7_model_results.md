# Phase 0.7: Baseline Model Results

## 1. Dataset Summary
The experiment was conducted on the leakage-free, temporally split matrices produced in Phase P0.6. 
*   **Prediction Point:** Loan Origination (no performance data used).
*   **Train Set:** 2007–2014 (453,809 rows)
*   **Validation Set:** 2015 36m (283,026 rows)
*   **Test Set:** 2016 36m (232,361 rows)
*   **Feature Dimensions:** 168 for Logistic Regression, 135 for XGBoost.

## 2. Class Distribution
The target variable (`default_flag`) exhibits a moderate class imbalance where defaults represent the minority class:
*   **Train Default Prevalence:** 17.03% (77,261 Defaults / 376,548 Non-Defaults)
*   **Validation Default Prevalence:** 14.89%
*   **Test Default Prevalence:** 19.85%

Due to this imbalance, accuracy is discarded as an evaluation metric. Models rely on class weighting instead of SMOTE for this baseline.

## 3. Model Configurations

### Logistic Regression (Interpretable Baseline)
*   `class_weight`: `'balanced'` (automatically scales penalization inversely proportional to class frequencies).
*   `max_iter`: `1000`
*   `penalty`: `'l2'` (Ridge, default `C=1.0`)
*   `random_state`: `42`

### XGBoost (Non-linear Benchmark)
*   `scale_pos_weight`: `4.87` (Calculated dynamically from the Train set: 376,548 / 77,261).
*   `n_estimators`: `300`
*   `max_depth`: `5`
*   `learning_rate`: `0.1`
*   `subsample`: `0.8`, `colsample_bytree`: `0.8`
*   `min_child_weight`: `10`
*   `reg_alpha`: `0.1`, `reg_lambda`: `1.0`
*   `eval_metric`: `'logloss'`
*   `random_state`: `42`

## 4. Training Results
*   **Logistic Regression Training Time:** 38.54 seconds. (Converged successfully).
*   **XGBoost Training Time:** 10.83 seconds. 

Both models fit efficiently without any reported data errors or infinities.

## 5. Validation Metrics (Threshold Independent)
These metrics summarize the models' raw probability ranking power on the validation set.

| Metric | Logistic Regression | XGBoost |
| :--- | :--- | :--- |
| **ROC-AUC** | 0.6996 | 0.7074 |
| **PR-AUC (Average Precision)** | 0.2739 | 0.2874 |

*XGBoost provides a slight lift in both ranking metrics, demonstrating non-linear interactions add value.*

## 6. Threshold Analysis
Validation probabilities were swept from `0.1` to `0.9` in 0.05 increments. 
Given the `balanced` (LR) and `scale_pos_weight` (XGB) settings, predicted probabilities naturally shift upward.

## 7. Selected Threshold & Rationale
For this baseline experiment, the threshold was selected dynamically by maximizing the **F1 Score** on the validation set.

> [!WARNING]
> **Business Rationale Note:** Maximizing the F1 Score assumes that False Positives (rejecting a good loan) and False Negatives (funding a default) carry approximately equal weight. In real-world credit origination, the financial loss of a default (loss of principal) is vastly higher than the opportunity cost of a rejected application (loss of interest margin). A true production threshold would optimize a financial Profit & Loss function rather than F1.

*   **LR Selected Threshold:** `0.50`
*   **XGB Selected Threshold:** `0.45`

## 8. Final Test Metrics
The models (and their selected validation thresholds) were frozen and evaluated exactly once on the 2016 Test cohort.

## 10. Interpretation of Results
*   **Signal Exists:** A Test ROC-AUC of ~0.70 indicates a moderate, valid credit-risk signal is present strictly at origination. This is aligned with industry baselines for consumer credit when post-origination performance data is strictly withheld.
*   **XGBoost Advantages:** XGBoost captures ~4,200 more true defaults (higher recall: 61.7% vs 52.6%) but at the expense of ~12,000 more false positives, largely driven by the threshold selection (0.45 vs 0.50). 
*   **Generalization:** The models generalized exceptionally well from the 2007–2014 training era to the 2016 test era (Test ROC-AUC actually matched/exceeded Validation ROC-AUC, partly due to the higher prevalence of defaults in 2016).

## 11. Limitations
*   **Not Production Ready:** These are Tier-1 baselines. They omit potentially powerful high-null schema features and high-cardinality geographic features (zip codes) which were deferred to Tier-2.
*   **Not a Causal Model:** The models identify correlations (e.g., specific loan purposes correlating with default) but do not establish causality.
*   **Fairness Unverified:** While direct sensitive attributes (race, gender) are absent from Lending Club data, proxies may exist within features like `addr_state` or `annual_inc`. A rigorous disparate impact analysis is required before applying this model to human applicants.
*   **Temporal Stability:** Credit markets shift macroeconomically. A model trained on 2014 data may rapidly degrade in a 2020+ environment. Regular recalibration is necessary.
