## 1. Objective

P0.9 is a **new calibration quality assessment experiment**. It does **not** modify, replace, or supersede any P0.7 result.

P0.7 delivered frozen baseline models, frozen thresholds (LR: 0.50, XGB: 0.45), and frozen evaluation metrics. Those are historical baseline results and must never be recomputed as a replacement.

**P0.9's single objective:** Assess the probability calibration quality of both frozen Tier-1 models using the existing validation dataset. Document whether predicted probabilities correspond reliably to observed default rates. Produce post-hoc isotonic calibration objects as P0.9 analytical artifacts for potential future use.

P0.9 does NOT:
- Tune the underlying models
- Add features or change hyperparameters
- Change the P0.7 thresholds
- Optimize or apply a new business or production threshold
- Use the test set
- Introduce SHAP, LLM, or RAG

## 4. Calibration Method

### 4.1 sklearn 1.8.0 API Compatibility Note

The original design specified:

```python
CalibratedClassifierCV(estimator=<frozen model>, cv='prefit', method='isotonic')
```

The `cv='prefit'` parameter was removed in scikit-learn 1.2. The installed environment uses scikit-learn 1.8.0.

**Approved replacement (Option A):**

> "Because scikit-learn 1.8.0 no longer supports cv='prefit', P0.9 implements the equivalent intended post-hoc calibration workflow explicitly: the frozen P0.7 model produces probability scores on the calibration-train subset, and an IsotonicRegression mapping is fitted on those scores and evaluated on a disjoint calibration-evaluation subset. The underlying base model is never refit."

This is methodologically identical to the original design intent.

### 4.2 Implemented Workflow

```python
# Step 1: extract base-model scores on cal-train (read-only forward pass)
scores_cal_train = frozen_model.predict_proba(X_cal_train)[:, 1]

# Step 2: fit isotonic mapping on those scores ONLY
iso = IsotonicRegression(out_of_bounds='clip')
iso.fit(scores_cal_train, y_cal_train)

# Step 3: apply to disjoint cal-eval
scores_cal_eval  = frozen_model.predict_proba(X_cal_eval)[:, 1]
calibrated_probs = iso.predict(scores_cal_eval)
```

The frozen base model parameters are **never modified**.

## 5. Reproducibility Specification

| Parameter | Value |
|:---|:---|
| `random_state` | 42 |
| Split method | `train_test_split(test_size=0.30, stratify=y_val, random_state=42)` |
| Cal-train size | ~198,118 rows (~70%) |
| Cal-eval size | ~84,908 rows (~30%) |
| Calibration method | `IsotonicRegression(out_of_bounds='clip')` |
| Calibration curve: primary | `n_bins=10, strategy='quantile'` |
| Calibration curve: cross-check | `n_bins=10, strategy='uniform'` |
| ECE definition | Weighted mean `|frac_pos - mean_pred|` per bin (quantile) |
| Brier Skill Score | `1 - (model_brier / noskill_brier)` |
| No-skill baseline | Always predict validation-set prevalence |
| Fingerprint tolerance | 1e-6 |

|:---|:---|
