## B. P0.9 Calibration Experiment

### B.1 Implementation

**Script:** `scripts/p09_calibration.py`

**Calibration method:** `IsotonicRegression(out_of_bounds='clip')` from `sklearn.isotonic`.

> **API Note:** The original design specified `CalibratedClassifierCV(cv='prefit', method='isotonic')`. That parameter was removed in scikit-learn 1.2. The installed environment uses scikit-learn 1.8.0. With explicit user approval (Option A), P0.9 implements the equivalent workflow directly: the frozen base model produces probability scores on the calibration-train subset; `IsotonicRegression` is fitted on those scores only; and the calibrator is evaluated on a disjoint calibration-evaluation subset. The base model is never refit.

### B.2 Data Roles

| Data | Role |
|:---|:---|
| Full validation set (283,026 rows) | Primary calibration measurement: calibration curves, Brier Score, ECE |
| Cal-train subset (~198,118 rows, 70%) | Isotonic calibrator fitted on base-model scores |
| Cal-eval subset (~84,908 rows, 30%) | Isotonic calibrator evaluated (disjoint from cal-train) |
| Test set | **Not used — prohibited** |

## C. Calibration Results

### C.1 Primary Metrics — Full Validation Set

| Metric | LR | XGB | No-skill Baseline |
|:---|:---|:---|:---|
| Brier Score | **0.190472** | **0.179901** | 0.126703 |
| Brier Skill Score | **−0.503304** | **−0.419870** | 0.000 |
| ECE (quantile, n=10) | **0.256286** | **0.234441** | — |

> **Interpretation:** Both models have **negative Brier Skill Scores**, meaning their raw probability outputs perform *worse* than a naive predictor that always predicts the observed default rate (14.89%). ECE values of ~0.23–0.26 are extremely high (well-calibrated models typically show ECE < 0.05). The predicted probabilities are severely miscalibrated.
>
> **ECE definition note:** ECE represents the weighted-average absolute gap between predicted default probability and observed default frequency across the calibration bins (quantile strategy, n=10). It should not be interpreted as a signed average overprediction in the sense of a simple arithmetic mean error. However, inspection of the bin-level table (`calibration_summary_lr.csv`, `calibration_summary_xgb.csv`) confirms that the observed gap is consistently in the direction of overprediction across all 10 bins for both models — i.e., `mean_predicted_value > fraction_of_positives` in every bin. The calibration curve (Section C.2) and the reliability diagrams provide the directional evidence; the ECE value quantifies the magnitude.

### C.2 Direction of Miscalibration

The reliability diagrams (see `results/calibration/calibration_curve_comparison_quantile.png`) show that both models **substantially overestimate** the probability of default across nearly all predicted-probability bins. Predicted probabilities are concentrated in the range 0.4–0.9, while true default rates in those bins remain closer to 0.1–0.5.

**Root cause (expected, documented in P0.9 design):** Both models applied class imbalance corrections — `class_weight='balanced'` for LR and `scale_pos_weight=4.87` for XGB. These corrections inflate minority-class (default) predicted probabilities far beyond their true conditional probabilities. The result is a systematic upward shift in predicted default probabilities relative to the observed default rate.

This is a **feature, not a bug**, for ranking tasks (ROC-AUC measures rank order, which is preserved). However, it renders the raw predicted scores unreliable as probability estimates, which is the purpose of this P0.9 investigation.

### C.3 Comparative Findings

- XGB is slightly less miscalibrated than LR (ECE: 0.234 vs 0.256; Brier: 0.180 vs 0.190), which is consistent with the design's prior expectation that logistic regression's linear structure may not handle the extreme class weighting as gracefully as XGB's tree structure in terms of calibration.
- Both models are strongly discriminating (ROC-AUC ~0.70), demonstrating that high ranking ability and poor calibration can coexist. **Discrimination and calibration are distinct properties.**

### C.4 Post-hoc Calibration — Cal-eval Subset (~30%)

> **Population scope:** All four columns in the table below (LR Base, LR Calibrated, XGB Base, XGB Calibrated) are evaluated on the **same 84,908-row calibration-evaluation subset** (stratified 30% hold-out from the validation set, `random_state=42`). The base-model columns use the frozen model's raw `predict_proba` scores on those rows; the calibrated columns use the isotonic-mapped scores on those same rows. This is a self-contained apples-to-apples comparison within the cal-eval population.
>
> The full-validation metrics in Section C.1 (283,026 rows) are descriptive baseline diagnostics characterising the base model's calibration on the entire validation set. They should not be directly compared numerically against Section C.4 values, because the two tables represent different (though overlapping) populations. The directional conclusion — that isotonic calibration dramatically reduces Brier Score and ECE — is supported within the cal-eval population independently.

| Metric | LR Base | LR Calibrated | XGB Base | XGB Calibrated |
|:---|:---|:---|:---|:---|
| Brier Score (cal-eval) | 0.190234 | **0.118501** | 0.179489 | **0.117551** |
| Δ Brier (base − cal) | — | **+0.071733** | — | **+0.061938** |
| ECE (quantile) | 0.256085 | **0.001110** | 0.234108 | **0.002453** |

Post-hoc isotonic calibration produces a dramatic improvement within the cal-eval population:
- Brier Score drops below the no-skill baseline (0.126703) for both models.
- ECE drops from ~0.25 to ~0.001–0.002, indicating near-perfect probability alignment after calibration.
- The calibrated objects are saved as `p09_calibrated_lr_isotonic.joblib` and `p09_calibrated_xgb_isotonic.joblib` in `results/calibration/`.

**These calibrated objects are P0.9 analytical artifacts only.** They are not the P0.7 baseline models and are not stored in `src/models/`.

## D. Probability Quality Interpretation

1. **The raw P0.7 model scores cannot be interpreted as reliable probability estimates.** A predicted score of 0.70 does not mean a 70% probability of default. The scores are reliable for ranking loans by risk (as evidenced by the ROC-AUC of ~0.70) but not for absolute probability assessment.

2. **Post-hoc isotonic calibration substantially corrects this.** After calibration, the ECE drops to ~0.001–0.002, indicating that the calibrated scores closely track observed default rates.

3. **Calibration does not change ROC-AUC.** Isotonic regression applies a monotonic transformation to the scores. Because ROC-AUC is rank-based, it is invariant to any monotonic score transformation. Calibration improves probability reliability without affecting discrimination.

4. **Calibration is not causality.** The finding that miscalibrated probabilities overestimate default risk does not imply any causal relationship between features and default. It reflects the construction of the model (class-weighting for imbalance) rather than a property of the underlying data generating process.

## E. Illustrative Threshold/Cost Analysis

> **This section is illustrative only. No threshold produced here is applied to the test set. No threshold produced here replaces the P0.7 frozen thresholds (LR: 0.50, XGB: 0.45). This is not a production threshold recommendation.**

The formula for the Bayes-optimal threshold under a cost-sensitive decision framework is:

```
p* = C_FP / (C_FP + C_FN)
```

where `C_FP` is the cost of a false positive (rejecting a good loan) and `C_FN` is the cost of a false negative (approving a defaulting loan). This formula holds **only when:**
1. Predicted probabilities are well-calibrated (satisfied after post-hoc calibration).
2. `C_FP` and `C_FN` are defined in the same monetary unit.
3. No portfolio constraints, regulatory floors, or concentration limits apply.

In real lending, determining `C_FN` (loss given default × exposure at default) and `C_FP` (foregone net interest income) requires actuarial data not available in this dataset. **Calibration is a necessary but not sufficient condition for business-optimal threshold selection.**

### Results (calibrated probabilities, cal-eval subset)

| Scenario | p\* | LR P / R / F1 | XGB P / R / F1 |
|:---|:---|:---|:---|
| F1 max (P0.7 ref, C_FP=C_FN=1) | 0.50 | 0.00 / 0.00 / 0.00 | 0.52 / 0.003 / 0.005 |
| Moderate loss aversion (C_FN=3×C_FP) | 0.25 | 0.31 / 0.34 / 0.32 | 0.32 / 0.33 / 0.33 |
| High loss aversion (C_FN=9×C_FP) | 0.10 | 0.20 / 0.84 / 0.33 | 0.20 / 0.85 / 0.33 |

**Notable finding at p\*=0.50 (LR):** After isotonic calibration, the LR model produces virtually no predictions above 0.50. This is consistent with the true default rate of ~14.9% — once probabilities are calibrated to reflect actual default rates, the 0.50 threshold (which was calibrated against inflated class-weighted scores in P0.7) becomes nearly vacuous. This underscores the importance of calibration in threshold selection.

Full results: `results/calibration/cost_threshold_illustration.csv`, `cost_threshold_illustration.png`.

## F. Limitations

1. **Calibration was performed on the validation set only.** Generalization to out-of-time data (2016+) is not assessed in P0.9.

2. **Isotonic regression can overfit on small datasets.** With ~198K cal-train rows this is unlikely to be severe, but the calibration improvement is evaluated on the held-out 30% subset only to mitigate this risk.

3. **The calibrated probabilities reflect the validation-set feature distribution (2015 cohort, 36 months).** If the feature distribution shifts over time, the calibration may degrade. Feature stability analysis is deferred to a future phase (P0.10 candidate).

4. **The cost-threshold formula uses hypothetical C_FP and C_FN ratios.** Real lending would require actuarial loss-given-default estimates and regulatory guidance.

5. **ECE is sensitive to bin count and binning strategy.** Results are reported for quantile binning (n=10) as primary and uniform binning as cross-check. Both are saved in the calibration summary CSVs.

6. **P0.9 does not examine miscalibration by sub-population** (loan grade, term, state). Potential heterogeneous miscalibration is deferred to the error analysis phase.
